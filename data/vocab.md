# プレイヤー用語集

記事を書く前に必ず読むこと。**ここにある語は、言い換えずにそのまま使う。**

「デッキが安定して動く」ではなく「回る」、「使いどころがない」ではなく「腐る」と書く。
読者はプレイヤーなので、外側の言葉で書かれた記事はすぐに見抜かれる。用語は検索キーワードでもあるため、
自然な言い換えに逃げると検索にも届かなくなる。

調査で新しい語に出会ったら、このファイルの末尾に追記すること（既存の行は消さない）。

> このファイルは内部資料。ここに載っているURLや出典を記事本文に書かないこと。

## 【主力】ヴァイスシュヴァルツロゼ

ヴァイスシュヴァルツ派生の美少女特化ブランド。2025年4月始動。基本のゲームルールは本家と同じ。

| 用語 | 意味 |
|---|---|
| OS番号 | タイトルの区分。コレクションID `**/～` の `**` の部分で判別する |
| ネオスタンダード構築 | タイトルを1つ選び、そのタイトルのカードのみで組む構築 |
| タイトル限定構築 | 指定された1タイトルのみで組む構築 |
| 特例カード | 複数タイトルのデッキに入れられる例外カード |

公式のデッキ構築ルール ver.1.04（2026年7月24日更新）で確認できた事実：

- タイトルは OS01〜OS15 で区分（ゆずソフト OS01、魔法少女にあこがれて OS02、HARUKAZE OS03、異種族レビュアーズ OS04、sprite、枕、AQUAPLUS、アリスソフト、Navel、ぬきたし THE ANIMATION、オーガスト、ぱれっと、ネコぱら セカイコネクト/ラブプロジェクト OS15 など）
- **同名カードは合算して4枚まで**。同名でも能力が異なるカードが存在する
- **同名でもOS番号が異なれば、相互のOS番号のカードとしては扱わない**（構築違反になりやすい落とし穴）
- 全タイトルで使える特例カード: `Happy Half Anniversary !!`（OS00/RPR-001）、`Happy 1st Anniversary !!`（OS00/RPR-002）
- ネオスタンダード構築の特例は、タイトル限定構築では適用されない

**未確認（記事で断定しないこと）**: 本家ヴァイスのカードをロゼのデッキに入れられるかは、上記PDFに明文がない。構築条件が「選択したタイトルのカードのみ」であることから入らないと読めるが、確認が取れるまで断定表現は避ける。デッキ50枚・クライマックス8枚も本家側のルールで、ロゼのPDFには記載がない。

### 会話専用（意味は知っておくが、記事では使わない）

読者との距離を測るために意味は把握しておくこと。ただし**記事に書くと品位が下がる**ため使わない。

| 用語 | 意味 | 記事で使わない理由 |
|---|---|---|
| 対よろ / 対あり | 「対戦よろしく」「対戦ありがとうございました」 | 対戦時の挨拶であり、記事の文体に合わない |
| じんかけ / じんおわ | 人生を賭ける / 人生が終わった | 射幸性を煽る文脈になりやすい |
| 舐めプ | 相手を軽んじたプレイ | 対戦相手を貶す語 |

## コレクター・売買まわり

`souba`・`kanbetsu`・`kaitori` テーマではこちらの語彙が中心になる。プレイ用語を無理に混ぜないこと。

### カードの状態

| 用語 | 意味 |
|---|---|
| 白かけ（白欠け） | 角や縁が欠けて下地が白く見える状態。状態評価で最も見られる箇所のひとつ |
| 初期傷 | 開封時点で既にある傷。点カケ、表面加工線、ホイル抜け、裏面の裁断荒れなど |
| 横線 | 製造工程でつく線状の傷 |
| ホロ欠け | ホログラム加工が剥がれている状態 |
| センタリング | 印刷位置が中央に収まっているか。ズレていると評価が下がる |
| コーナー / エッジ | 角 / 縁。状態は「角・縁・表面・センタリング」の4点で見る |
| 美品 | 目立った傷がない良好な状態 |
| 完美品 | 肉眼で傷や汚れが確認できない状態 |
| ミント / NM（ニアミント） | 新品同様 / わずかな傷がある新品に近い状態 |
| プレイ用 | 傷はあるが対戦で使うには支障がない状態 |

### 鑑定

| 用語 | 意味 |
|---|---|
| グレーディング | 傷・白かけ・センタリング・角の状態を採点して等級をつけること |
| スラブ | 鑑定後にカードを封入する専用ホルダー。認証番号とグレードが表示される |
| サブグレード | センタリング・コーナー・エッジ・表面を個別に採点した内訳 |

> 禁止されているのは**ショップ名・買取店名・販売事業者名**であり、鑑定機関はこれに当たらないと解釈する。
> 既存記事 `souba-psa10-kakaku-sa-2026-08` も同じ扱い。

## 使うときの注意

- 専門用語を並べただけの記事にはしない。**初出の語は1回だけ短く説明を添える**。「初動（序盤に動き出すための札）」のように。
- 初心者向け（guide）記事では、用語を使いつつ必ず説明を入れる。用語を避けるのではなく、使って教える。
- 相場（souba）や真贋（kanbetsu）の記事では、プレイ用語を無理に入れない。そこはコレクター寄りの語彙が中心になる。

### デジモンカードゲーム（プレイ中の言い回し）

| 用語 | 意味 | 使いどころ |
|---|---|---|
| 返し / 1返し・2返し | メモリーを相手側のいくつまで渡してターンを終えるか | メモリー管理の中心語。「初手は1〜2返し」 |
| 返しすぎ | 相手に多くメモリーを渡してしまうこと | 失敗を指す言い方 |

> 「自分が動くこと＝相手への供給」という構造から入ると通じやすい。

### 保管・状態（反りの語彙）

| 用語 | 意味 | 使いどころ |
|---|---|---|
| 谷反り | 絵柄面が内側に丸まり、皿のように凹んだ状態。**高湿度**が原因（裏面の紙が膨張する） | 反りの話は方向を言わないと対処が決まらない |
| 山反り | 絵柄面が盛り上がり、裏面に向かって反った状態。**低湿度**が原因（紙が収縮する） | 谷反りと対で使う |
| 折れ筋 | 一度折れてついた線。**反りと違って環境では戻らない** | 物理的に曲げて直すことのリスクを説明するとき |

> 反りの仕組みは**紙の層とホイル層の伸縮率の差**。紙は湿度で伸縮し、箔は伸びない。だから
> **箔の載った面積が広いカードほど反りが強く出る**。「光物ほど反る」は印象ではなく構造。
> 適正湿度の目安は **40〜60%**（45〜50%が目安として挙がることが多い）。
> スリーブは摩擦には効くが**湿度への防御にはならない**（内側が曇る事例がある）。

> 留保の定型は「基本的には」「大体」「あくまで1例」「結局のところ好きな人が最強」。

### ヴァイスシュヴァルツ（レベル1〜3の言い回し・追加分）

| 用語 | 意味 | 使いどころ |
|---|---|---|

| 用語 | 意味 |

> 「個人的な感想」「定石など語れるほどではない」。
